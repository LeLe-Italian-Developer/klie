## [1.0.0] – 2026-06-05

### Added
- Initial public release
- Local AI inference (on-device model)
- Character chat with personality system
- World building (locations + lore)
- Creator gallery (browse & download characters)
- Offline mode with hardware-locked license (7-day window)
- Checkpoint system (conversation snapshots)
- Memory system (persistent character memories)
- Multi-platform builds: macOS, Windows, Linux, Android
- Auto-updater via Tauri updater protocol
- App PIN + biometric lock
- Screenshot protection
