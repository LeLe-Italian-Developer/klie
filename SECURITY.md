# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅ Yes    |

---

## Reporting a Vulnerability

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, report them privately via email:

📧 **support@klie.app**

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Your suggested fix (optional)

### Response Timeline

| Stage | Target |
|---|---|
| Acknowledgement | 48 hours |
| Initial triage | 5 business days |
| Fix / patch | 30 days (for critical issues) |

### Scope

In scope:
- Remote code execution
- Authentication bypass
- License bypass / DRM circumvention
- Data exfiltration from the local database

Out of scope:
- Issues requiring physical access to the device
- Denial of service on the local app
- Social engineering

---

## Disclosure Policy

We follow **Coordinated Disclosure**. After a fix is shipped, we will publish a security advisory crediting the reporter (unless they prefer anonymity).
